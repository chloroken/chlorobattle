Pawn Code:

		- attackNameDescription (for all variables)
		- nameAttackScene (for packedscene references)
	Attack Variables:
		- isAttackFlag
		- attacks only contain effect variables
	all @exports typed as narrow as possible
Pawn Nodes:
	- Custom nodes above inherited nodes
	- $NamePawn (e.g., ChairPawn)
	- $AttackDescriptionTimer (e.g., $MeowCooldownTimer)
	- $AttackContainer (holds attacks/effects)
	Attack Nodes:
		$NameAttack

		# The order depends on pawn mechanics

		# For dynamic cycles, it must go in disarm_check() block
		new_attack_cycle(cdMin, cdMax)
		if disarm_check(): return
